🚗 Vehicle Dashboard – Market Analysis in Excel

I’m excited to share my latest Excel project — a Vehicle Market Analysis Dashboard that offers powerful insights for decision-makers in the automotive industry.

📊 Main Dashboard Sections:

Sales Overview – Analyze revenue, regional sales, dealer performance & sales trends

Customer Insight – Identify color preferences, gender-based analysis, and buyer behavior

Vehicle Insight – Explore interest across body styles, transmission types, engine types, and more

⚙️ Tools & Features Used:

Power Query for efficient data transformation

Pivot Tables, Slicers, and Formulas

KPI indicators and interactive charts

Fully linked sheets with navigation buttons

Dynamic filtering (monthly/yearly) with real-time updates

Designed for market analysis and strategic decision-making support in the vehicle industry.
